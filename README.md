# Social Resume: The Intern Challenge

A classroom game about Clough & Wu (2022), "Artificial Intelligence, Data-Driven
Learning, and the Decentralized Structure of Platform Ecosystems."

Play it: open `index.html`, or use this repository's GitHub Pages link.

Controls: → / Space / Page Down = next · ← / Page Up = back ·
A–D = select an answer · N = presenter notes · F = full screen
